# Project Description (한글)

Swagger 문서를 보면서 어느 순간 API 를 구현했는데, 어느 순간 API 응답 구조가 바뀌는 것을 보았습니다.
API 문서와 화면단 구현 시점에 대하여 기록할 수 있는 기능이 있으면 좋겠다는 생각이 들어 이 프로젝트를 만들게 되었습니다.



목적은
- API 문서 변경 diff 감지
- API 프론트 구현 상태 [ OK, Pre, ING, NOT ]
  - diff -> 수정필요 화면 보여주기 ( OK 이후 수정된 경우 )
  - 담당자, 진행율, 진행날짜
- 구현된 API, 미구현된 API 분류보기
